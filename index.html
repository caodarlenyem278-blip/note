⚡ 跨设备同步

手机和电脑使用相同的 GitHub Token 和 Gist ID 实时同步（3 秒轮询）。Token 不会过期。

⚪ 未连接
📖 首次使用设置步骤（GitHub Gist 版） ▶

第一步：创建永久 Token。打开 github.com/settings/tokens → 选 Tokens (classic) → Generate new token。勾选 gist 权限，Expiration 选 No expiration，生成后把 ghp_… 开头的字符串复制下来。

第二步：主设备创建 Gist。在数据较多的一台设备（一般是手机）打开本页，填入 Token，点击「📝 自动创建新 Gist」。页面会出现一个 32 位 Gist ID，把它记下来。

第三步：另一台设备同步。在第二台设备填入相同的 Token 和 Gist ID，点击「连接」。系统会把 Gist 的最新数据拉下来，手机端的本地数据也会自动传上去（双向汇合）。

第四步：日常使用。两边都保持页面打开或偶尔打开一次即可，3 秒内自动双向同步。

⚠️ 安全提示：Token 等同于密码，请勿发给别人/截图上传。建议只勾选 gist 权限（不需要 repo 权限也能用本同步）。如果怀疑泄露，到 这里 立刻 Revoke 并重生。
